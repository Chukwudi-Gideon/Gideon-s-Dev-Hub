# Developer Portfolio

 This is a quality responsive portfolio built with a focus on typography, fast loading speed and accessibility.


# Live Demo link = https://gideon-s-dev-hub.vercel.app/
## 🚀 Tech Stack
 Frontend: React, TypeScript, Tailwind CSS
 Icons: Lucide React
 Forms/API: Formspree API Integration

## 🛠️ Key Features
 Fluid Dark Mode: I personally have problems with websites that do not have white and darkmode fo accessiblity purposes, well I took my own advice and made dure it contains a smooth background color transitions optimized to minimize digital eye strain.

 Asynchronous Form Handling: It  validates contact forms with real-time UI loading states connected to Formspree API Backend, providing users with instant feedback on submission status.


 Responsive Architecture: The grid layouts scales gracefully from mobile screens up to wide desktops.
